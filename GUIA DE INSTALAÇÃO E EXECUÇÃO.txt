GUIA DE INSTALAÇÃO E EXECUÇÃO

Se estás a ler isto, é porque o projeto está no vosso PC e precisam
de o pôr a funcionar. Sigam os passos exatamente como estão aqui.
Sem pressa, sem pular etapas.


═══════════════════════════════════════════════════════════
PASSO 1 — LIGAR O XAMPP
═══════════════════════════════════════════════════════════

Abram o XAMPP Control Panel e cliquem em "Start" nos dois:
  - Apache
  - MySQL

Se o MySQL não ligar, é porque já têm outro MySQL instalado.

═══════════════════════════════════════════════════════════
PASSO 2 — BASE DE DADOS (ESCOLHEM UMA OPÇÃO)
═══════════════════════════════════════════════════════════

Antes de mais, se o vosso PC já tem uma base de dados antiga
e defeituosa do projeto, APAGUEM primeiro no phpMyAdmin.
Depois escolham uma das opções abaixo.

── OPÇÃO A (RECOMENDADA) — USAR O BACKUP ──

O backup da BD foi extraído hoje e contém todos os dados atuais.
Ficheiro: backups/backup.sql

Passos:
  1. Abram http://localhost/phpmyadmin
  2. Cliquem em "Novo" (menu à esquerda)
  3. Nome da base de dados: sgf
  4. Collation: utf8mb4_unicode_ci
  5. Cliquem em "Criar"
  6. Com a base de dados sgf selecionada, vão ao separador "Importar"
  7. Escolham o ficheiro backup.sql
  8. Cliquem em "Executar"
Pronto. Dados todos no sítio, sem erro.

── OPÇÃO B — EXECUTAR O SCRIPT COMPLETO ──

Se preferirem criar tudo do zero com o script completo
(não o diagrama .mwb, mas sim o ficheiro .sql com os INSERTs):

  1. Abram BANCO DE DADOS/BD.sql (ou o script completo)
  2. Abram http://localhost/phpmyadmin
  3. Cliquem em "SQL" (separador no topo)
  4. Colem todo o conteúdo do ficheiro
  5. Cliquem em "Executar"

Isto cria as tabelas e insere os dados de teste todos de uma vez.


═══════════════════════════════════════════════════════════
PASSO 3 — CONFIGURAR A CONEXÃO
═══════════════════════════════════════════════════════════

Abram o ficheiro: MODEL/DAO/conexao.php

Verifiquem estas linhas:
  private $host = "localhost";
  private $dbname = "sgf";
  private $username = "root";
  private $password = "";       ← Atenção aqui!

Se o MySQL do vosso PC NÃO TEM SENHA (padrão do XAMPP):
  - Deixem a password vazia ("")

Se o MySQL do vosso PC TEM SENHA:
  - Escrevam a vossa senha aqui
  - Exemplo: private $password = "minhasenha";

Se der erro "Não foi possível ligar a base de dados":
  - Abram o XAMPP e vejam se o MySQL está a rodar
  - Verifiquem se a base de dados "sgf" existe no phpMyAdmin - esse phpMyAdmin é o mesmo que usar Mysql, só que online
  - Confirmem que o utilizador é "root" e a senha está correta


═══════════════════════════════════════════════════════════
PASSO 4 — INTERNET LIGADA (OBRIGATÓRIO)
═══════════════════════════════════════════════════════════

O projeto usa Bootstrap e Bootstrap Icons via CDN (links online).
Sem internet, os ícones não aparecem e o layout quebra.

Verifiquem se estão online antes de testar. Os CDNs usados:
  - Bootstrap 5 (CSS e JS)
  - Bootstrap Icons
  - Font Awesome (na página pública)
  - Google Fonts (Inter)
